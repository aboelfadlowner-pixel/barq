# الداتابيز — نجم أبو الفضل (Supabase / Postgres)

الملفات دي هي **المصدر الوحيد** لشكل الداتابيز. اتراجعت على Supabase الحقيقي: كل الدوال والجداول وقواعد الأمان مطابقة 100%.

## الترتيب (لو هتبني داتابيز جديدة من الصفر)
1. `migrations/001_tables.sql`: الجداول والأعمدة والفهارس.
2. `functions/auth.sql` ← `scoring.sql` ← `save.sql` ← `league.sql` ← `votes.sql` ← `payouts.sql`
3. `policies/rls.sql` ← `policies/storage.sql`
4. `seed/defaults.sql`: حساب `ops` (رقم سري `0000`، غيّره أول دخول) والإعدادات.
5. `seed/employees.sql`: الـ 175 موظف (اختياري، التطبيق ممكن يحمّلهم بنفسه).

## قواعد التعديل
- **جدول أو عمود جديد** = ملف جديد في `migrations/` برقم أكبر (`002_...sql`). **متعدّلش ملف اتنفذ قبل كده.**
- **تعديل دالة** = عدّلها في مكانها في `functions/` (كل دالة مكتوبة مرة واحدة بس)، ونفّذ الملف على Supabase.
- **قاعدة أمان** = `policies/`.
- بعد أي تعديل: شغّل `tests/` (فيها اختبارات الداتابيز والصلاحيات).

## نموذج الأمان
- **الموظفين:** بيفتحوا من غير دخول، وبيقروا البيانات العامة بس (الأسماء والصور، مجموع النجوم، الفايزين، التارجت، المبيعات). **مش بيشوفوا** البنود ولا الشكاوى ولا الملاحظات ولا الحسابات.
- **المديرين:** يوزر + رقم سري (مشفّر sha256 + salt). كل كتابة بتعدّي على `najm_save` اللي بتتأكد من الدور والنطاق (الفرع / الشيفت / الأقسام). **مفيش أي جدول عليه صلاحية كتابة مباشرة.**
- **5 محاولات دخول غلط** ← الحساب بيتقفل 15 دقيقة.
- **الحسبة في مكان واحد:** `najm_score` بتحسب نجوم اليوم، والتطبيق بيعرض اللي الداتابيز حسبته.

## الجداول
| الجدول | فيه إيه |
|---|---|
| `najm_employees` | الموظفين: الكود، الاسم، الفرع، القسم، الوظيفة، الشيفت، الصورة، الفيديو، اللقب |
| `najm_users` | حسابات المديرين: الدور (ops / branch / shift / fresh / hygiene)، النطاق، الرقم السري المشفّر، كود الموظف |
| `najm_ratings` | تقييم كل موظف كل يوم: البصمة، فرع / شيفت / فريش / تشغيل / هايجين (5 بنود من 0 لـ 2)، التصرف المثالي |
| `najm_winners` | رجل اليوم لكل فرع وشيفت |
| `najm_targets` | تارجت كل قسم في الشهر (منتجات وكميات، أو مؤشرات)، ونقط القسم والمطلوب |
| `najm_captains` | الكابتن: موظف + منتج + كمية + نقط (مدير التشغيل بس اللي بيحدد النقط) |
| `najm_sales` / `najm_base_sales` | مبيعات فودكس اليومية / مبيعات الشهر اللي فات للتخطيط |
| `najm_kpi_vals` | أرقام مؤشرات الأقسام اللي مش بتبيع |
| `najm_cards` | الكروت (الأحمر محتاج موافقة التشغيل) |
| `najm_complaints` / `najm_notes` | شكاوى العملاء / ملاحظات الإدارة |
| `najm_settings` / `najm_private` | الإعدادات العامة / الإعدادات المخفية (مكافأة التارجت بالفلوس) |
| `najm_mgr_ratings` / `najm_mgr_ledger` | تقييم التشغيل اليومي للمديرين / رصيد نقطهم |
| `najm_market` / `najm_offers` | سوق الانتقالات / عروض المديرين |
| `najm_votes` | تصويت الموظفين (صوت لكل كود ولكل جهاز في الشهر) |
| `najm_payouts` | الجوايز اللي اتصرفت |
| `najm_upload_tokens` / `najm_login_fails` | توكن رفع الصور / محاولات الدخول الغلط |
